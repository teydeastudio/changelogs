== Changelog ==

= 1.2.0 (2026-10-30) =
* Editors can undo an automated expiry with a new "Restore previous status" action in the Posts and Pages lists, and the Expiry column shows the status a post had before it expired
* Fixed expiry dates set across a daylight saving change being stored an hour off
* Personal-data exports now include notification recipient memberships, and erasure requests remove the user from the recipients
* Accessibility: the Expires date field in the document sidebar and the Timed Content block now has a label
* A canceled scheduled action now stays canceled when it was already running
* Saving settings now reports an error when WordPress refuses the database write
* The minimum supported WordPress version is now 6.8
* Dependencies updated
* Code improvements

= 1.1.1 (2026-10-12) =
* Fixed roles and users past the tenth not being selectable in the settings
* Editor panel open/closed and enabled/disabled preferences are now remembered between page loads
* Dashboard widget table rows are now announced by screen readers with the post they belong to
* Dependencies updated
* Code improvements

= 1.1.0 (2026-08-28) =
* Plugin renamed to "Teydea Content Expiry", with a new icon and updated links
* Compatibility with WordPress 7.1 confirmed
* Fixed help text not being announced as the description of the field it belongs to on the settings and editor screens
* Fixed a successful settings save reporting itself as failed on WordPress 6.6
* Plugin banners and screenshots added to the WordPress.org listing
* Dependencies updated
* Code improvements

= 1.0.3 (2026-06-22) =
* Added the plugin icon
* Settings page tabs are now reflected in the URL, so a tab can be bookmarked and shared
* Added a clear admin notice for unmet server requirements (minimum PHP/WordPress version, required extensions)
* Dependencies updated
* Code improvements

= 1.0.2 (2026-04-27) =
* An FAQ entry added to readme.txt, explaining where the unminified source code lives in the plugin and how to rebuild it from source

= 1.0.1 (2026-04-24) =
* The "Pre-expiry warning" and "Dashboard widget window" settings now accept any number of days within a reasonable range, with quick-set presets for common values
* Direct loading of wp-includes/version.php in the WordPress version detection fallback removed

= 1.0.0 (2026-04-07) =
* The first stable release
